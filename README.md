# 🎤 智能提词器 - Web版

一个功能完整的网页版提词器，支持语音跟随滚动，可在手机端和电脑端直接使用。

## ✨ 功能特性

### 核心功能
- **文本输入区**：支持粘贴或输入任意长度的台词内容
- **提词显示区**：中央大字滚动显示，适合演讲、主持等场景
- **语音跟随**：使用 Web Speech API 实时识别语音，说话时自动滚动，停止说话时暂停
- **响应式设计**：完美适配手机端和电脑端

### 控制面板
- **行宽调节**：30-80字符范围，优化文本换行显示
- **字号调节**：20-80px范围，适应不同视力需求和屏幕尺寸
- **滚动速度**：1-10级可调，满足不同语速需求
- **操作控制**：开始/暂停/重置按钮

## 🚀 快速开始

### 在线使用
1. 访问部署在 GitHub Pages 的页面
2. 在文本输入区粘贴或输入台词内容
3. 调整行宽、字号、速度等参数
4. 点击"开始滚动"开始提词
5. 如需语音跟随，点击"语音跟随"按钮并允许麦克风权限

### 本地使用
1. 下载 `index.html` 文件
2. 用浏览器直接打开即可使用
3. 无需安装任何依赖

## 🎯 使用指南

### 基本操作
1. **输入台词**：在文本输入区输入或粘贴您的演讲内容
2. **调整参数**：
   - 行宽：控制每行显示的字符数（建议50-60字符）
   - 字号：调整显示文字大小
   - 速度：控制滚动速度（1最慢，10最快）
3. **开始提词**：点击"开始滚动"按钮
4. **控制播放**：使用"暂停"按钮临时停止，"重置"按钮回到开头

### 语音跟随功能
1. 点击"语音跟随"按钮
2. 允许浏览器使用麦克风
3. 开始说话，提词器会自动滚动
4. 停止说话时，提词器会自动暂停
5. 再次点击按钮可关闭语音跟随

### 浏览器兼容性
- **最佳支持**：Chrome、Edge（推荐）
- **语音功能**：仅 Chrome/Edge 支持完整语音识别
- **其他浏览器**：可正常使用除语音外的所有功能

## 🔧 技术实现

### 核心技术
- **纯前端实现**：HTML5 + CSS3 + JavaScript
- **语音识别**：Web Speech API（SpeechRecognition）
- **动画效果**：requestAnimationFrame 实现平滑滚动
- **响应式布局**：Flexbox + Media Queries

### 语音跟随原理
1. 使用 `webkitSpeechRecognition` 或 `SpeechRecognition` API
2. 实时监听用户语音输入
3. 检测到语音时自动开始滚动
4. 语音停止时自动暂停滚动
5. 支持中文语音识别

## 🌐 部署指南

### GitHub Pages 部署
1. 创建新的 GitHub 仓库
2. 将 `index.html` 和 `README.md` 上传到仓库
3. 在仓库设置中启用 GitHub Pages
4. 选择主分支作为源
5. 访问生成的 `https://[用户名].github.io/[仓库名]`

### 自定义域名
1. 在仓库设置中添加自定义域名
2. 配置 DNS 解析
3. 等待 SSL 证书自动生成

## ⚠️ 注意事项

1. **语音识别**：需要 HTTPS 环境或 localhost 才能使用
2. **浏览器权限**：首次使用语音功能需要授权麦克风
3. **网络环境**：语音识别需要网络连接
4. **隐私保护**：语音数据由浏览器处理，不会上传到服务器
